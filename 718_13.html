Aide-mémoire — Design du livre numérique du futur

1. Formats du livre

  • ePub / EPUB 3 — HTML/CSS/XML · reflow · multimédia · ouvert
    • roman, essai, manuel ; livrel standard
  • PDF — page / impression · ouvert* · homothétique, POD
  • MOBI / AZW / KF8 — Kindle · propriétaire · Amazon
  • HTML — livre-web · ouvert · Abrüpt, antilivres
  • IBA / apps · DAISY / PDF-UA · MD / XML · Audio
    • *souvent verrouillé par DRM

Reflowable vs Fixed-layout

  • Reflowable — texte s’adapte à l’écran / préférences
    • roman, essai, manuel · pas de « p. 12 » → titres / liens
  • Fixed-layout (FXL) — page dessinée fixe ; zoom / pan
    • BD, album, magazine · composition proche print

2. Modes multi

  • Multisupport — plusieurs objets de lecture
    • ex. Révolutions (objet rare + site)
  • Multiformat — plusieurs fichiers, idéalement une source
    • ex. Abrüpt (HTML + PDF + EPUB + Git)
  • Multimodal — texte + voix + image + geste
    • ex. EPUB 3 vidéo ; livre-app
≠ live / web-to-print / single source / autoporté

3. Types / remédiations

  • Homothétique — proche du papier · PDF « page », EPUB classique
  • Enrichi / augmenté — texte + médias · EPUB 3, Parcours numériques
  • Nativement numérique — conçu pour le numérique · Afternoon, Twine
  • Hybride — papier ↔ écran · Alto (Révolutions, Borodine), POD

4. Outils — avantages / inconvénients (1/2)

  • Sigil / Calibre — + contrôle EPUB · − technique, exports parfois sales
  • Affinity / InDesign / Scribus — + maquette fine · − homothétique, EPUB limité
  • Pandoc + Markdown — + single source, Git · − courbe d’apprentissage
  • Twine — + gratuit, HTML · − peu « livre-objet » commercial
  • Storyspace — + guard fields · − payant, Mac, pérennité
  • WordPress / CMS — + familiarité · − templates, dépendance

4. Outils — avantages / inconvénients (2/2)

  • Manifold — + OA, annotation · − install, public académique
  • AO3 — + tags, archive · − pas un outil de design maison
  • Wattpad — + masse, feedback · − algo, monétisation
  • Are.na / print — + sans algo, web-to-print · − niche
  • TimelineJS / StoryMapJS — + prêts à l’emploi · − formats imposés
