Publier un site web — création, hébergement, nom de domaine

Publier un site web

  • Donner accès aux navigateurs
    • aux fichiers HTML, CSS, JavaScript
  • pour afficher l’information

Client / serveur

Côté Rôle
Client Navigateur : on saisit une URL → requête HTTP
Serveur Ordinateur (physique ou virtuel) qui sert les fichiers ; le navigateur les interprète
Un serveur stocke et délivre ; chez soi, en data center, ou via un prestataire.

Trois étapes récurrentes

  • 1. Créer un site web
    • HTML à la main, ou avec un CMS
  • 2. Choisir un hébergeur
    • espace où sont stockées les données
  • 3. Avoir un nom de domaine
    • adresse web — URL

1. Créer un site web

  • En HTML à la main
  • ou avec un CMS (Content Management System)
    ou avec SSG (Static Site Generator)

2. Choisir un hébergeur

  • Espace où vont être stockées les données
  • certains systèmes hébergent et publient
    • GitHub Pages, WordPress…

3. Avoir un nom de domaine

  • Adresse web — URL
    • via des services en ligne (registrars)
  • parfois couplé à l’hébergement
  • coûts variables selon l’extension et le prestataire

Modes de création
1. À la main (HTML et CSS)

  • HTML : balises du texte
  • CSS (Cascade Style Sheets) : allure, mise en page
  • + JavaScript : fonctionnalités
    • recherche, boutons avec effet…
  • Long, complexe, technique
    • Mais : vous avez la main sur tout ce qui constitue le site

Modes de création
2. Via CMS

  • Interfaces plus ou moins simplifiées
    • WordPress (~43 % des sites), Squarespace, Wix
  • Modèles plus complexes
    • Drupal, Ghost — interfaces graphiques
  • Vraiment techniques : générateurs de sites statiques
    • Hugo, Eleventy — pas d’interface graphique
  • Création facilitée
    • Mais contrainte aussi par des modèles / templates
  • Souvent : offre d’hébergement et options payantes
    • ou du « tout-en-un » comme WordPress.com

Le choix d’outil oriente la publication
